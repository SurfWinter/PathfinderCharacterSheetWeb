# Лист персонажа Pathfinder 2e

Статический лист, версия **1.4.0** (с фиксом отрисовки: предметы, ячейки, тумблеры, режим игры обновляются сразу, без F5).

Данные в браузере (`localStorage`). Перенос персонажа — XML.

## Как опубликовать на GitHub Pages

1. Создайте **публичный** репозиторий, например `pf2-sheet`.
2. Залейте **содержимое этого архива в корень** (не во вложенную папку):
   - `index.html`
   - `404.html`
   - `favicon.svg`
   - `.nojekyll`
   - папка `assets/`
   - `README.md`
3. Репозиторий → **Settings → Pages**.
4. Source: Deploy from a branch → `main` / `/ (root)`.
5. Сайт: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

Если уже заливали прошлый архив — замените файлы целиком (имена JS другие, чтобы сбросить кэш) и подождите 1–2 минуты.

## После открытия

Персонажи из превью сюда сами не переедут. **Настройки → Импорт** XML.

Не открывайте `index.html` с диска — нужен адрес GitHub Pages.
